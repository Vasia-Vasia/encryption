Вам предстоит написать программу, которая шифрует сообщения по следующему алгоритму: она берет текст и переставляет в нем каждые два подряд идущих символа.

Если количество символов нечетное, то последний символ остается на своем месте:

encrypt("move") # 'omev'  
encrypt("attack") # 'taatkc'  
encrypt("go!") # 'og!'

Реализуйте функцию encrypt(), которая принимает на вход исходное сообщение и возвращает зашифрованное.
